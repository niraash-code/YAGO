# YAGO Documentation

YAGO (Yet Another Game Organizer) is a high-performance mod manager for 3DMigoto-compatible games.

## Supported Games

- **HoYoverse**: Genshin Impact, Honkai: Star Rail, Zenless Zone Zero
- **Wuthering Waves**

More games will be added in the future.
