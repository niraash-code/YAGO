# Safety & Streamer Mode

YAGO includes features to protect your account and stream.

## Streamer Mode

Keep your stream safe from sensitive content:
- **Blur**: NSFW mod cards are blurred in the UI
- **Text Obfuscation**: Mod names and tags are hidden
- **Panic Switch**: Press **F12** to instantly hide everything

## Anti-Ban Measures

- **Non-Destructive**: YAGO never modifies game files
- **Safe Injection**: Uses conservative injection methods
- **Metadata Stripping**: Screenshots have EXIF data removed
